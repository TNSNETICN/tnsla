LYRANIX ARCADE — FINAL UPLOAD BUILD

Upload the contents of this folder to your web root.

1. Put your authorized SWF files directly in /games/ using the exact filenames in games/README.txt.
2. Open index.html through your domain.
3. Search, Info, Play, Favorites, Recently Played, and Save Data are already wired.

THUMBNAILS
The Papa's/Papa Louie thumbnails use external Flipline screenshot URLs. They remain external as requested.

SAVE DATA
Supported Flash games use Ruffle's browser persistence for their own Flash SharedObject save data. Users can right-click inside the Ruffle player and use Ruffle's Save Manager to export/import supported game saves.

Lyranix stores favorites/recent games locally. The Save Data page backs up that Lyranix profile metadata separately.

No account, database, or server-side save system is required for this version.

Ruffle is loaded from the official web package CDN. For a fully self-hosted runtime, replace the CDN script with Ruffle's official self-hosted web package.
