About Lyranix Arcade

Lyranix Arcade

Lyranix Arcade is a browser-based gaming portal built by Lyranix for playing authorized classic game content through modern web technology.

Powered by Ruffle

Ruffle is an open-source Flash emulator that allows supported Flash content to run in modern browsers. Lyranix Arcade uses Ruffle as the browser playback layer.
